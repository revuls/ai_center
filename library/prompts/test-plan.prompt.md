Create a test plan for:

{{feature: story, acceptance criteria or description}}

Include:
1. Scope and out of scope.
2. Test cases (table with ID, title, steps, expected result, priority and level: unit/integration/E2E/manual).
3. Required test data.
4. Relevant non-functional tests (security, accessibility, performance).
5. Exit criteria.
